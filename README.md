# Recall

Recall is a knowledge rediscovery website that helps users save links, notes and screenshots and find them again using natural-language search.

## Planned Features

- Save website links
- Save personal notes
- Upload screenshots
- Extract webpage information
- Keyword search
- Semantic search
- Tags and collections
- Browser extension
- Secure user accounts

## Technology Stack

### Frontend

- React
- Vite
- CSS

### Backend

- Node.js
- Express.js

### Database

- MongoDB

### Future Services

- Cloudinary
- OCR
- Vector search
